# Skill Name: 古今历史事件匹配大师
# Description: 将现代新闻事件与中国古代历史事件进行精准匹配，从底层逻辑分析相似性和差异性，提炼具有现实意义的历史启示。所有历史信息均通过实时搜索获取，确保准确可靠。
# Author: 历史分析专家
# Version: 1.1
# Tags: 历史分析, 新闻解读, 古今对比, 搜索增强

## 输入参数
- `news_content`: 现代新闻的标题或简要内容（必填）
- `max_candidates`: 最多返回的候选历史事件数量（可选，默认值：3）
- `min_score`: 最低匹配分数阈值（可选，默认值：60，满分100）


## 执行流程
当用户调用此技能时，严格按照以下7个步骤执行，不得省略任何步骤：

### 步骤1：新闻事件结构化拆解
将用户提供的新闻内容按照以下5个维度进行拆解，提炼核心信息：
- 背景：事件发生的时代背景和前置条件
- 核心矛盾：事件最根本的冲突和问题所在
- 关键人物：事件中的主要角色及其行为模式
- 主要措施：各方采取的关键行动和策略
- 结果影响：事件已经产生或可能产生的后果

### 步骤2：领域定位与搜索Query生成
#### 2.1 领域定位
使用以下11个领域分类，确定事件的主领域和次领域：
【核心领域】政治事件、军事战争、经济事件
【支柱领域】文化与意识形态、社会与民生、科技与工程、法律与制度
【延伸领域】民族与边疆、能源与资源、环境与气候、公共卫生

#### 2.2 生成搜索Query
根据拆解结果，生成3组不同类型的搜索Query，每组2-3个：
- **精准匹配Query**："中国古代类似[核心矛盾]的事件"、"历史上[关键行为]的例子"
- **领域通用Query**："中国古代[主领域]史上的重大事件"、"历代[核心问题]案例"
- **反向验证Query**："[现代事件]与中国古代哪个事件最相似"

### 步骤3：调用搜索工具获取历史事件
- 依次执行你生成的所有搜索Query
- 从搜索结果中筛选出**5个最常被提及**的候选历史事件
- 对于每个候选事件，单独搜索其详细信息，包括：时间、朝代、背景、核心矛盾、关键人物、主要经过、结果影响
- 优先使用维基百科、百度百科、中国历史网等权威来源的信息,优先采取《资治通鉴》、二十四史中的史料。
- 对于关键历史事实，必须在至少两个不同的权威来源中进行交叉验证

### 步骤4：历史事件信息提取与标准化
将每个候选历史事件的信息标准化为以下格式：
```
事件名称：XXX
朝代：XXX
时间：XXX年
背景：XXX
核心矛盾：XXX
关键人物：XXX
主要经过：XXX
结果影响：XXX
信息来源：XXX
```

### 步骤5：多维度相似度评分
使用以下5维评分表对每个标准化后的历史事件进行量化评估（满分100分）：
| 评估维度 | 权重 | 评分标准 |
|---------|------|---------|
| 核心矛盾 | 30分 | 底层逻辑和因果关系是否完全一致 |
| 背景条件 | 20分 | 社会环境和时代背景是否相似 |
| 人物角色 | 15分 | 关键人物的身份和行为模式是否对应 |
| 发展过程 | 15分 | 事件的演进阶段和关键节点是否雷同 |
| 结果影响 | 20分 | 最终结局和历史影响是否相通 |

### 步骤6：结果筛选与排序
- 淘汰所有得分低于`min_score`的事件
- 按照总得分从高到低对剩余事件进行排序
- 保留前`max_candidates`个事件作为最终匹配结果

### 步骤7：生成分析报告
选择得分最高的历史事件进行深度分析，然后按照下面的固定格式输出完整的分析报告。

## 质量控制规则
1. **拒绝表面相似**：必须基于事件的因果关系和运行规律进行匹配，禁止简单的标签化类比（如"当代曹操"）
2. **信息可验证**：所有历史信息都必须标注信息来源，禁止输出没有搜索支持的内容
3. **客观中立**：尊重历史事实，不歪曲历史，不用现代标准苛责古人
4. **明确差异**：必须指出古今事件的本质差异和时代局限性，避免简单化类比
5. **时间限制**：只匹配1840年鸦片战争以前的中国古代历史事件
